# User Roles and Use Cases

| Role | Primary capabilities |
|---|---|
| Pump Operator | Capture plate, verify compliance, view result, retry low-confidence OCR |
| Pump Supervisor | All operator capabilities plus review exceptions and station analytics |
| Traffic Police | Verify vehicles in field, view evidence, capture enforcement notes |
| Compliance Reviewer | Investigate manual-review cases and provider discrepancies |
| Administrator | Manage users, roles, stations, provider configuration and rules |
| Auditor | Read-only access to immutable verification/audit records |

## High-value use cases
1. Fast verification at a CNG filling point.
2. Roadside compliance verification by traffic police.
3. Expired compliance detection.
4. Missing/not-found certificate handling.
5. Low-confidence plate recognition with user correction.
6. Compliance-provider outage with queued/retry workflow.
7. Audit reconstruction of who checked which vehicle, using which data source and rule version.
